Privacy Policy

Last updated: September 7, 2026 | Website: www.studysphere.it.com

Android App (com.studysphere.app)

The StudySphere Android app collects no data and shares no data. There is no account, no login, no server, and no analytics or advertising SDK of any kind. Every task, plan, note, flashcard, exam, and setting you create is stored only in a local database on your device.

The app never sends anything over the network. The only permissions it uses are: notifications (for a reminder when a task is due, only if you turn reminders on), vibration (for haptic feedback on the focus timer and task actions), and limited legacy storage access used only on very old Android versions for the manual backup feature described below.

Your data, your device. Settings includes "Export my data," which saves everything to a file you control (for moving to a new phone), and "Delete all data," which permanently erases everything on the device. Because there is no account, there is nothing on a server to delete — deleting on-device is complete deletion.

"Sage" and the notes summarizer inside the app are local, deterministic features, not an AI model — they never send your notes or tasks anywhere.

Website — data stored on device

The StudySphere website (this site) stores student profile details, tasks, plans, notes, flashcards, grades, reminders, and login activity locally in your browser so it can work without requiring an account server.

Website — consent

Students are asked for consent before profile and activity data is saved. The site uses this data to personalize planning, reminders, and progress views.

Free access

StudySphere does not process payments. All included student tools are free.

Admin access

The website's admin page has no shipped password and is disabled by default. It is not present in the Android app at all.

User Choices

Users can clear app data from the Android system settings by clearing StudySphere storage. A production backend release should also provide account deletion and data export options.

Contact

For privacy and support requests, use the in-app feedback form. Messages are sent to the StudySphere team at tijalabs@gmail.com when server delivery is configured.
